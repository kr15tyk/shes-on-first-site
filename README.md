# She's On First

The website for **She's On First**, an independent women's baseball media and documentation project building a sourced record of the Inaugural 60.

## Local development

```bash
npm install
npm run assets:prepare
npm run dev
```

## Production build

```bash
npm run build
```

## Brand assets

The original transparent logo is stored at `assets/brand/shes-on-first-logo-transparent.png`. Run `npm run assets:prepare` to regenerate the optimized website logo and favicon.

She's On First is independent and is not affiliated with or endorsed by the Women's Pro Baseball League.
